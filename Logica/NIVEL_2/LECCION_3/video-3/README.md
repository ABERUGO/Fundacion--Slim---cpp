# Ejercicios de Lógica de Programación - C y C++

Este repositorio contiene soluciones a ejercicios de lógica y estructuras de datos, desarrollados durante mi proceso de aprendizaje autónomo y formación técnica.

*   **Fuente de los ejercicios:** Curso de Lógica de Programación de la Fundación Slim.
*   **Implementación y desarrollo:** Realizados por mí, como estudiante de ADSO (SENA).

## 🚀 Tecnologías utilizadas
*   **C**: Implementación de punteros, gestión de memoria y estructuras unidimensionales.
*   **C++**: Manejo de matrices bidimensionales y bucles anidados.

## 📂 Contenido
*   `punteros.c`: Ejercicio de uso de punteros y direcciones de memoria.
*   `estructuras_unidimensionales.c`: Inserción de elementos en arreglos.
*   `matriz.cpp`: Lectura y escritura de una matriz de 4x4.
